# Contributing to IRON MIKE 🥊

Thank you for your interest in contributing to **IRON MIKE**!

IRON MIKE is a browser-based boxing game built using **HTML, CSS, and JavaScript**. Contributions, suggestions, bug fixes, and improvements are welcome.

---

## 📌 How to Contribute

### 1. Fork the Repository

Fork the IRON MIKE repository to your own GitHub account.

### 2. Clone the Repository

Clone your fork to your computer:

```bash
git clone https://github.com/your-username/iron-mike.git
```

Move into the project directory:

```bash
cd iron-mike
```

### 3. Create a New Branch

Create a separate branch for your changes:

```bash
git checkout -b feature-name
```

For example:

```bash
git checkout -b improve-combo-system
```

---

## 🛠️ Making Changes

Before making changes, make sure you understand the existing project structure.

You can contribute by:

* Fixing bugs
* Improving game controls
* Adding new game features
* Improving animations
* Improving the UI
* Adding sound effects
* Improving enemy behavior
* Improving performance
* Fixing spelling or documentation issues

Try to keep changes simple and focused.

---

## 💻 Code Guidelines

### HTML

* Keep the HTML structure clean and organized.
* Use meaningful IDs and class names.
* Avoid unnecessary elements.

### CSS

* Keep styles organized.
* Use clear class names.
* Avoid unnecessary duplicate styles.

### JavaScript

* Use meaningful variable and function names.
* Keep functions focused on one task.
* Add comments when the logic is difficult to understand.
* Avoid unnecessary global variables.
* Test keyboard controls after making changes.

---

## 🎮 Testing Your Changes

Before submitting a contribution, test the game in a modern web browser.

Make sure to check:

* Game starts correctly
* Keyboard controls work
* Punches work correctly
* Blocking works correctly
* Health updates correctly
* Stamina updates correctly
* Combos work correctly
* Timer works correctly
* Enemy attacks work correctly
* Sounds work correctly
* Win/Lose/Draw results work correctly
* Restart functionality works correctly

---

## 🐛 Reporting Bugs

If you find a bug, create a GitHub Issue and provide:

1. A short description of the problem
2. Steps to reproduce the issue
3. What you expected to happen
4. What actually happened
5. Browser and operating system
6. Screenshots or videos, if useful

### Example

```text
Bug: Block button stops working

Steps to reproduce:
1. Start Fight Mode
2. Press SPACE to block
3. Continue pressing SPACE after an enemy attack

Expected:
The player should continue blocking.

Actual:
The block action stops responding.
```

## 💡 Suggesting Features

New feature ideas are welcome.

When suggesting a feature, explain:

* What the feature does
* Why it would improve the game
* How it could work
* Any possible changes required

Examples:

* New boxing characters
* New arenas
* Character selection
* New combos
* Improved enemy AI
* Mobile controls
* New game modes

## 🔀 Pull Requests

After completing your changes:

### 1. Check your changes

```bash
git status
```

### 2. Add your files

```bash
git add .
```

### 3. Commit your changes

```bash
git commit -m "Add new boxing feature"
```

### 4. Push your branch

```bash
git push origin feature-name
```

### 5. Open a Pull Request

Create a Pull Request on GitHub and briefly explain:

* What you changed
* Why you changed it
* How you tested it

---

## 📝 Commit Messages

Try to keep commit messages short and descriptive.

Good examples:

```text
Add combo attack system
Fix stamina regeneration
Improve blocking animation
Update game instructions
Fix fight timer
Improve enemy attack logic
```

Avoid unclear messages such as:

```text
changes
update
fixed stuff
final
new code
```
